The mark is not derived from any third-party artwork. It is generated from a
parametric equation — a Gaussian-windowed sine wave — by tools/make_logo.py:

    y(t) = A · exp(-((t - 0.5)²) / (2σ²)) · sin(2π · cycles · t)

Run `uv run python tools/make_logo.py` to regenerate it; edit the constants at
the top of that file to change amplitude, frequency, stroke or colour.
